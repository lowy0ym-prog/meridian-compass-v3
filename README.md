# Kosher GPS

A phone-first Android GPS/navigation app with:
- OpenStreetMap street map and optional satellite imagery.
- Device GPS without Google Play Services.
- Place/address search using OpenStreetMap Nominatim.
- Live driving route using OSRM.
- Route line, distance, ETA, and basic maneuver steps.
- Wikimedia Commons place-photo search with a preference for exterior/building images and avoidance of obvious people/interior keywords.
- Source labels for map/photo providers.
- Local assistant commands such as “take me to Times Square”, “where am I”, and “show satellite”.
- Optional OpenAI/ChatGPT assistant. Add your own API key in the app; it is stored locally on the phone and is never committed to GitHub.

The public OSM services have usage limits and attribution requirements. This build is intended for personal testing and can switch providers later if needed.
